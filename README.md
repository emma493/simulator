# My Website Clone

A static website clone ready for **GitHub + Cloudflare Pages** deployment.

## Project structure

```
my-website-clone/
├── src/                    # Put your cloned HTML/CSS/JS/assets here
│   ├── index.html
│   ├── pages/
│   ├── assets/
│   │   ├── css/
│   │   ├── js/
│   │   ├── images/
│   │   ├── videos/
│   │   └── fonts/
│   └── ...
├── dist/                   # Build output (generated by npm run build)
├── scripts/
│   ├── build.js            # Copies src -> dist
│   └── dev.js              # Local dev server
├── _headers                # Cloudflare Pages custom headers
├── _routes.json            # Cloudflare Pages routing rules
├── wrangler.toml           # Cloudflare Wrangler config
├── package.json            # npm scripts
├── deploy.sh               # One-command deploy script
└── README.md
```

## Quick start (local)

```bash
# Install dependencies
npm install

# Start local dev server (http://localhost:5173)
npm run dev

# Build for production (src -> dist)
npm run build
```

## Deploy to Cloudflare Pages

### Option A: Manual deploy (one command)

```bash
chmod +x deploy.sh
./deploy.sh
```

This installs deps, builds `src/` → `dist/`, and deploys to Cloudflare Pages via Wrangler.

### Option B: Connect GitHub repo to Cloudflare Pages (auto-deploy)

1. Push this repo to GitHub.
2. Log in to Cloudflare Dashboard → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Select your `my-website-clone` repository.
4. Configure build settings:
   - **Framework preset:** None (or HTML)
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
   - **Production branch:** `main`
5. Click **Save and Deploy**.

Every push to `main` will now auto-deploy to Cloudflare Pages.

## Next steps (when you have the source code)

1. Drop your cloned website files into `src/`.
2. Run `npm run dev` to preview locally.
3. Run `npm run build` + `./deploy.sh` to publish.
